# .github — GoldSrc.rs Organization Meta Repository

This special repository hosts the organization-wide profile, brand resources, and default community health templates for the **[GoldSrc.rs](https://github.com/goldsrc-rs)** organization.

## Contents

- **[profile/README.md](profile/README.md)** — Public landing page rendered on the [Organization Profile](https://github.com/goldsrc-rs).
- **[SECURITY.md](SECURITY.md)** — Organization-wide security disclosure policy.
- **[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)** — Contributor Covenant 2.1 Code of Conduct.
- **[CONTRIBUTING.md](CONTRIBUTING.md)** — Default contribution guidelines for all repositories.

## Key Repositories

- **[`goldsrc`](https://github.com/goldsrc-rs/goldsrc)** — Technical umbrella, facade meta-crate, developer CLI (`grs`), and architectural hub.
- **[`goldsrc-runtime`](https://github.com/goldsrc-rs/goldsrc-runtime)** — High-performance host engine, Metamod & Standalone backends, Wasmtime runtime.
- **[`goldsrc-sdk`](https://github.com/goldsrc-rs/goldsrc-sdk)** — Pure Rust guest SDK and procedural macros for writing plugins.
- **[`goldsrc-plugins-standard`](https://github.com/goldsrc-rs/goldsrc-plugins-standard)** — Standard suite of official WASM plugins.
